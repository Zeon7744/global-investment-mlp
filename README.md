## 简介

多因子量化投资框架，适用于美股、港股、加密货币市场。提供风险调整后的选股模型和压力测试能力。

## 核心特性

- 四类因子: 动量、价值、质量、波动
- 风险调整选股模型
- 压力测试与情景分析
- 回测引擎支持
- 多市场适配

## 支持市场

- 美股 (S&P 500, Nasdaq)
- 港股 (恒生指数成分)
- 加密货币 (BTC, ETH, ALT)
